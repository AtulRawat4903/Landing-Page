# Dog Lovers Landing Page

A simple landing page built as part of The Odin Project Foundations curriculum.

## About

This project is a static landing page themed around dogs. It was created to practice HTML, CSS, Flexbox layouts, and Git workflows.

## Features

* Responsive header with navigation links
* Hero section with call-to-action button
* Dog breed showcase section
* Inspirational quote section
* Newsletter sign-up call-to-action
* Footer with copyright information

## Built With

* HTML5
* CSS3
* Flexbox
* Git & GitHub

## What I Learned

Through this project, I practiced:

* Structuring webpages with semantic HTML
* Building layouts using Flexbox
* Styling components with CSS
* Working with images and typography
* Creating meaningful Git commits
* Managing a project using GitHub

## Future Improvements
